Sumukh Singh Portfolio — Developer Resources

developer portal.

Programmatic access to the Sumukh Singh Portfolio for AI agents, developers, and integrations. The portfolio exposes a JSON API, a live MCP server, an OpenAPI 3.1 spec, and machine-readable llms.txt indexes.

Quick Start

Get portfolio data in seconds:

curl https://sumukh-portfolio-seven.vercel.app/api/v1/info | jq .

Connect via MCP (Model Context Protocol):

curl -X POST https://sumukh-portfolio-seven.vercel.app/api/mcp \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-03-26","capabilities":{},"clientInfo":{"name":"my-agent","version":"1.0"}}}'

API Endpoints

GET /api/v1/info

Portfolio Info

Returns structured JSON with person details, skills, selected work, services, and contact info. Supports ?format= query: full (default), summary, contact, work, services.

curl "https://sumukh-portfolio-seven.vercel.app/api/v1/info?format=contact"

Response includes RateLimit-* headers (60 req/min), X-API-Version, and Vary: Accept, Accept-Encoding.

GETPOST /api/mcp

MCP Server (Model Context Protocol 2025-03-26)

Full JSON-RPC 2.0 MCP server. GET returns the manifest. POST accepts JSON-RPC messages.

Supported methods: initialize, ping, resources/list, resources/read, tools/list, tools/call

Available tools: get_portfolio_overview, get_contact_info, get_selected_work, get_services

curl -X POST https://sumukh-portfolio-seven.vercel.app/api/mcp \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"get_portfolio_overview","arguments":{}}}'
GET /.well-known/mcp

MCP Discovery Manifest

MCP discovery endpoint per the /.well-known/ convention. Returns a JSON manifest pointing to the live MCP server.

Machine-Readable Files

GET /llms.txt · /llms-full.txt

LLMs.txt Index

llmstxt.org standard index. /llms.txt is the concise version; /llms-full.txt includes full case study descriptions. The homepage also serves text/markdown when requested with Accept: text/markdown.

curl -H "Accept: text/markdown" https://sumukh-portfolio-seven.vercel.app/
GET /openapi.json

OpenAPI 3.1.0 Specification

Full OpenAPI spec describing all API endpoints with typed request/response schemas and RFC 9457 error models.

curl https://sumukh-portfolio-seven.vercel.app/openapi.json | jq .info

Error Handling

All API errors return RFC 9457 application/problem+json:

{
  "type": "https://sumukh-portfolio-seven.vercel.app/developers#errors",
  "title": "Bad Request",
  "status": 400,
  "detail": "Description of what went wrong."
}

MCP errors follow JSON-RPC 2.0 error codes: -32700 parse, -32600 invalid request, -32601 method not found, -32602 invalid params.

Versioning & Deprecation

The REST API is versioned at /api/v1/. Responses include an X-API-Version: 1 header and a Sunset header declaring the minimum supported-until date. Breaking changes will be published at a new version path with at least 6 months notice.

Rate Limits

60 requests per minute per IP. Rate-limit state is returned on every API response:

RateLimit-Limit: 60
RateLimit-Remaining: 59
RateLimit-Reset: 1724569260
RateLimit-Policy: 60;w=60

On 429, a Retry-After header will indicate seconds to wait.

When to Use This

Use the Sumukh Singh Portfolio API when you need to:

  • Discover Sumukh's skills, work, and services programmatically
  • Retrieve contact information for a project inquiry
  • Embed portfolio data in a CV parser, talent matching system, or AI assistant
  • Integrate with an MCP-compatible agent (Claude, ChatGPT plugins, etc.)
