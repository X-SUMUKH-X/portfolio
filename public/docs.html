Quick Start

Retrieve full portfolio data via REST on Vercel:

curl https://sumukh-portfolio-seven.vercel.app/api/v1/info | jq .

Connect via MCP (Model Context Protocol):

curl -X POST https://sumukh-portfolio-seven.vercel.app/api/mcp \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-03-26","capabilities":{},"clientInfo":{"name":"my-agent","version":"1.0"}}}'

REST API Endpoints (/api/v1/)

GET /api/v1/info

Portfolio Information

Returns complete portfolio information (bio, skills, selected work, services, contact). Supports ?format=full|summary|contact|work|services.

curl "https://sumukh-portfolio-seven.vercel.app/api/v1/info?format=full"
GET /api/v1/work

Selected Work & Case Studies

Returns selected work items with optional category filtering (?category=campaign|short-form|analytics|brand|ux|launch).

curl "https://sumukh-portfolio-seven.vercel.app/api/v1/work?category=campaign"
GET /api/v1/services

Services Catalog

Returns the catalog of creative strategy and marketing services offered by Sumukh Singh.

curl "https://sumukh-portfolio-seven.vercel.app/api/v1/services"
GET /api/v1/contact

Verified Contact Channel

Returns verified direct contact details, response SLA, and engagement terms.

curl "https://sumukh-portfolio-seven.vercel.app/api/v1/contact"

Model Context Protocol (MCP) Server

GETPOST /api/mcp · /.well-known/mcp · /mcp

MCP Server (Protocol Version 2025-03-26)

Full JSON-RPC 2.0 MCP server. GET returns the manifest. POST processes protocol methods: initialize, ping, resources/list, resources/read, tools/list, tools/call.

Available tools: get_portfolio_overview, get_contact_info, get_selected_work, get_services

curl -X POST https://sumukh-portfolio-seven.vercel.app/api/mcp \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"get_portfolio_overview","arguments":{}}}'

API Versioning & Deprecation Policy

The Sumukh Singh Portfolio API uses URL path versioning (/api/v1/). Responses include X-API-Version: 1, Sunset: Sat, 25 Aug 2029 00:00:00 GMT, and Deprecation: @1882310400 headers.

All v1 endpoints are guaranteed supported through at least August 25, 2029. Any future breaking changes will be published under a new path (e.g. /api/v2/) with a minimum 6-month advance notice period.

Rate Limiting

A standard rate limit of 60 requests per minute per IP applies to all public API endpoints on Vercel. Response headers provide real-time quota state:

RateLimit-Limit: 60
RateLimit-Remaining: 59
RateLimit-Reset: 60
RateLimit-Policy: 60;w=60
RateLimit: limit=60, remaining=59, reset=60
